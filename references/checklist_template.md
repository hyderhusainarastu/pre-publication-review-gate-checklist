# Publication review gate

**Current status: PENDING EXTERNAL REVIEW — DO NOT PUBLISH.**

`PENDING` is an intentional blocking state. Preparing this package does
not certify professional, legal, or accessibility compliance — only an
independently evidenced item, or an explicit acceptance by a named
accountable owner, does.

## Claims

- [ ] Every capability or feature claimed in public copy is demonstrated
      in the current, actually-shippable build.
- [ ] Screenshots and demo media match the build being offered and
      contain no fabricated data presented as real (see the synthetic
      content disclosure file for anything intentionally illustrative).
- [ ] Goal, limit, deadline, price, and status language match the
      canonical source of truth for that value.
- [ ] No undisclosed companion property, private beta, or unreleased
      surface is referenced in public material.
- [ ] No institution, individual, press outlet, partner, or backer is
      presented as endorsing the product without written authorization
      on file.
- [ ] Every metric, total, audience count, and testimonial is sourced
      and dated.

## Accessibility

- [ ] Independent WCAG 2.2 AA (or current target standard) review
      completed for every public surface.
- [ ] Keyboard order, visible focus, headings, landmarks, link text,
      disclosure widgets, and form labels verified directly.
- [ ] 200% zoom and reflow pass completed.
- [ ] Reduced-motion behavior verified.
- [ ] Image, carousel, social-image, video, and audio alt text,
      captions, transcripts, and audio-description scripts approved.
- [ ] Any 3D/canvas/non-text visualization has a parity accessible
      fallback verified against identical data and filters.
- [ ] Downloadable document reading order, tagging, links, contrast, and
      selectable text verified.

## Privacy and security

- [ ] Data controller, contact, jurisdiction, subprocessors, third-party
      model/service providers, storage locations, retention,
      encryption, logging, and incident process documented and
      approved.
- [ ] Any model-training-use statement matches actual provider
      contracts and production configuration.
- [ ] Account/data deletion covers uploads and derived data, with
      current test evidence.
- [ ] Cross-user authorization, private-data access, export, and
      deletion tests pass.
- [ ] Cohort/survey data minimization reviewed.
- [ ] Security review identifies release-blocking findings and
      remediation owners.

## Copyright and intellectual property

- [ ] Upload terms and lawful-use guidance reviewed by counsel.
- [ ] Third-party excerpts, thumbnails, frames, quotations, and
      citations shown publicly are rights-cleared.
- [ ] Synthetic or placeholder imagery, personas, and records are
      disclosed appropriately (see synthetic content disclosure file).
- [ ] Font, media, narration, icon, and software licenses recorded.
- [ ] Trademark/logo search and visual-conflict review completed.
- [ ] No full third-party work or full-resolution protected image is
      redistributed without authorization.

## Content and factual integrity

- [ ] Factual/reference claims resolve to real, checkable, authoritative
      sources.
- [ ] Quotations match inspected original sources exactly.
- [ ] Named real people credited as experts/creators/examples have
      independently verified identity and credentials.
- [ ] Distinct quality dimensions (peer review, rigor, expertise,
      provenance, evidence strength, relevance, popularity) remain
      visibly separate, never collapsed into one score.
- [ ] An anonymous or unverified social source never solely supports a
      factual or evaluative claim.
- [ ] Genuine competing interpretations or open uncertainty remain
      visible where they exist.
- [ ] If the product evaluates/scores content, that evaluation's own
      error/fabrication rate, provenance completeness, and performance
      on representative (not only favorable) cases have been measured.

## Commercial terms (mark N/A with a one-line reason if not applicable)

- [ ] Current payment-processor/platform/marketplace terms confirmed
      against terms actually in force.
- [ ] Tax/legal adviser reviewed jurisdiction, income recognition, sales
      tax/VAT, reserve, and reward/fulfillment treatment.
- [ ] Labor and vendor cost estimates support the stated price or goal.
- [ ] Fulfillment capacity, infrastructure cost, and support load
      stress-tested against realistic demand.
- [ ] Failed-payment, refund, chargeback, and currency handling
      documented.
- [ ] Stretch goals / future commitments stay unpublished until
      separately costed and scheduled.

## Final release decision

- [ ] All critical findings closed or explicitly accepted by a named
      accountable owner.
- [ ] Final URLs, dates, times, terms, privacy policy, and contact
      channels inserted (no drafting placeholders remain).
- [ ] All public surfaces (site, app, social, email, downloadable
      material) reconcile on shared values.
- [ ] A final archive snapshot of claims/financial figures has been
      created.
- [ ] Publication authorization recorded in the decision log (who,
      when, what residual risk if any was accepted).
